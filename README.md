### 🔨 Selected work

**Helpdesk Ticket Triage LLM** · *final-year project*
Fine-tuned **Mistral-7B with LoRA** to turn a support ticket into structured JSON (category, priority, fix steps).
→ **100%** valid JSON and **93.3%** priority accuracy on held-out tickets, shipped as a 4-bit GGUF that runs offline through Ollama.
`Python` `Unsloth` `LoRA` `Ollama`

**Maison Center** · *hotel booking platform*
Customer app and admin portal where double bookings are impossible by design, enforced by a PostgreSQL exclusion constraint and a retrying booking function. Live admin board and email confirmations.
`React` `Express` `Supabase` `PostgreSQL`

**Support Hub** · *built for an employer*
Admin dashboard that takes over viewer screens (one device, a group, or all) to play a chosen support video live, with role-based access and upload approval.
`React` `Vite` `Supabase`
