01about

I'm a Computer Engineering graduate from KNUST in Kumasi, Ghana. My work sits where software engineering meets applied AI.

On the AI side, I've fine-tuned Mistral-7B with LoRA to triage support tickets and run it fully offline, and built a signal-processing classifier that tells appliances apart from a single current reading. On the software side, I build full-stack React + PostgreSQL platforms where the database itself guarantees correctness.

I'm most interested in applied machine learning, adapting and deploying foundation models efficiently, and the engineering that makes AI systems dependable.

02projects

  • Helpdesk Ticket Triage LLM

    final-year project

    Fine-tuned Mistral-7B with LoRA to turn a support ticket into structured JSON (category, priority, fix steps). Reached 100% valid JSON and 93.3% priority accuracy on held-out tickets, then shipped as a 4-bit GGUF that runs offline through Ollama.

    • Python
    • Unsloth
    • LoRA
    • Ollama

  • Maison Center

    hotel booking

    Customer app and admin portal for a hotel. Double bookings are impossible by design, enforced by a PostgreSQL exclusion constraint and a retrying booking function. Includes a live admin board and email confirmations.

    • React
    • Express
    • Supabase
    • PostgreSQL

  • Harmonic Load Disaggregation

    signal processing + ML

    Identifies which appliances are running from a single current signal using filtering, harmonic-ratio features and k-NN (macro-F1 0.98). A voltage-sag gate halved false switching events.

    • Python
    • DSP
    • k-NN

  • Support Hub

    built for an employer

    An admin dashboard that takes over viewer screens (one device, a group, or all of them) to play a chosen support video live, with role-based access and approval for uploads.

    • React
    • Vite
    • Supabase

  • Husky Mobile Robot Control

    robotics

    A proportional controller that drives a simulated Clearpath Husky to a target from laser-scan data, plus EKF localisation on recorded runs. Traced a steering fault to an inverted laser mount.

    • ROS Noetic
    • Gazebo
    • RViz
